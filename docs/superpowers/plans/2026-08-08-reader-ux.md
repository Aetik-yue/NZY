> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 完善 5 项高价值低成本阅读体验（段距可调 / 预取下一章 / 进度滑块 / 哨兵页重试 / 翻页上一章衔接）+ 代码拆分（`novel_reader_page.dart` 863 行 -> <300、`novel_detail_page.dart` 376 行 -> <300）+ 修复 build 内副作用。

**评估两种顺序：**

| 维度 | 先功能后拆分 | **先拆分后功能（采用）** |
|---|---|---|
| 红线状态 | 功能加完 863 -> ~980 行，更久处于违规态 | 拆分后立即合规，功能在新小文件上加 |
| 功能改动定位 | 集中在 novel_reader_page 几个方法 | 每个功能映射到明确的拆分文件（段距->scroll_mode+paginator；预取->fetcher mixin；滑块->controls+build；重试->placeholders+page_mode；衔接->fetcher mixin） |
| 拆分风险 | 末尾拆分要移动含新功能的更多代码 | 拆分是纯机械移动+验证，功能建在已验证结构上 |
| build 副作用 | 6 个任务持续违反 CLAUDE.md | 拆分任务中一次性修复 |

**采用先拆分的理由：** (1) 文件已 3x 超红线，应优先降风险；(2) 拆分是机械提取+`flutter analyze/test` 验证，行为保持，功能建其上安全；(3) 每个功能在拆分后有明确归属文件，并非「散落多文件」而是「各有其家」；(4) build 副作用（`_settings`/`_latestChapters` 赋值 + `addPostFrameCallback`）是现存违规，尽早修复避免后续任务继承。

### 设计要点

**拆分策略（两层）：**
1. **UI 渲染层**抽 StatelessWidget：`ReaderScrollMode`（接收 settings/textColor/scrollChapters/showEndHint/fetchingNext/controller，纯渲染）、`ReaderPageMode`（接收 settings/textColor/pages/isLastChapter/controller/onPageChanged/onChapterEndRetry/autoAdvancing/autoAdvanceFailed，纯渲染）。分页缓存字段（`_paginateContent` 等）与分页计算留在主 State（在 build 中作为 memoized 派生计算，仅本文件可见），算出 `pages` 后传给 Widget。
2. **逻辑层**用 `part` 文件 mixin：Dart mixin 在独立文件无法访问主 State 的私有字段（私有为库级可见）。用 `part 'reader_chapter_fetcher.dart';` 使 mixin 与主文件同库，mixin 内可读写 `_novel`/`_loadingChapterId`/`_scrollChapters` 等私有字段，避免改公有或传参爆炸。

**build 副作用修复（spec 明确要求移出）：**
- `_settings = settings;` -> 改用 `ref.listenManual(readerSettingsProvider, ...)` 在 initState 缓存到 `_settings` 字段（`fireImmediately: true`）。
- `_latestChapters = chapters;` -> 改用 `ref.listenManual(chaptersProvider(widget.novelId), ...)` 在 initState 缓存到 `_latestChapters`（排序后赋值）。
- `addPostFrameCallback`（_maybeRestore + _ensureChapterContent）-> 改为「调度式」：在两个 listen 回调中调用 `_schedulePostFrameWork()`，该方法用 `_postFrameScheduled` 守卫注册一次 post-frame 回调，回调内执行 restore/fetch/prefetch。回调在帧末布局完成后执行，控制器已有 clients，可安全 jumpToPage/jumpTo。

**关键代码要点 - 主文件 initState：**

```dart
@override
void initState() {
  super.initState();
  SystemChrome.setEnabledSystemUIMode(SystemUiMode.immersiveSticky);
  _currentChapterIndex = widget.initialChapterIndex;
  _scrollController = ScrollController()..addListener(_onScroll);
  _pageController = PageController();
  ref.read(readerSettingsRepositoryProvider).getOrCreate();
  ref.listenManual<AsyncValue<ReaderSettings?>>(readerSettingsProvider,
      (prev, next) {
    next.whenData((s) {
      _settings = s;
      _schedulePostFrameWork();
    });
  }, fireImmediately: true);
  ref.listenManual<AsyncValue<List<NovelChapter>>>(
      chaptersProvider(widget.novelId), (prev, next) {
    next.whenData((list) {
      _latestChapters = [...list]
        ..sort((a, b) => a.chapterIndex.compareTo(b.chapterIndex));
      _schedulePostFrameWork();
    });
  }, fireImmediately: true);
  // keepScreenOn listen 保留原样
  ref.listenManual<AsyncValue<ReaderSettings?>>(readerSettingsProvider,
      (prev, next) { /* keepScreenOn wakelock 逻辑不变 */ },
      fireImmediately: true);
  ref.read(novelRepositoryProvider).getById(widget.novelId).then((n) {
    if (!mounted) return;
    _novel = n;
    setState(() {});
  });
}

bool _postFrameScheduled = false;
void _schedulePostFrameWork() {
  if (_postFrameScheduled) return;
  _postFrameScheduled = true;
  WidgetsBinding.instance.addPostFrameCallback((_) {
    _postFrameScheduled = false;
    if (!mounted) return;
    final s = _settings;
    final chapters = _latestChapters;
    if (s == null || chapters.isEmpty || _novel == null) return;
    final idx = _currentChapterIndex.clamp(0, chapters.length - 1);
    _maybeRestore(s, idx);
    _ensureChapterContent(chapters, idx);
    _prefetchNextChapter(chapters, idx); // Task 4 接入，此处先留空调用
  });
}
```

> 注意：原 build 中 `_settings = settings;` 和 `_latestChapters = chapters;` 删除；build 仅读取 provider 的 AsyncValue 取 `settings`/`sorted`/`effectiveIndex` 传给 `_buildReader`，不再写字段。post-frame 已由 listen 调度，build 不再注册回调。

**关键代码要点 - _buildReader 委托渲染：**

```dart
Widget _buildReader(BuildContext context, ReaderSettings settings,
    List<NovelChapter> chapters, int effectiveIndex) {
  final theme = settings.bgTheme;
  final bg = AppColors.readerBg(theme);
  final textColor = AppColors.readerTextOn(theme);
  final chapter = chapters.isEmpty ? null : chapters[effectiveIndex];
  final content = chapter?.content ?? '';
  final chapterTitle = chapter?.title ?? '';
  final paddingTop = MediaQuery.of(context).padding.top;
  final paddingBottom = MediaQuery.of(context).padding.bottom;

  final Widget readingArea;
  if (settings.pageMode == 0) {
    // 滚动模式：同步 _scrollChapters 后委托 ReaderScrollMode
    _syncScrollChapters(settings, chapters, effectiveIndex);
    final showEmpty = _scrollChapters.isEmpty ||
        _scrollChapters.first.content.isEmpty;
    readingArea = showEmpty
        ? _buildEmptyContent(settings, textColor, chapterTitle)
        : ReaderScrollMode(
            settings: settings, textColor: textColor,
            scrollChapters: _scrollChapters,
            showEndHint: _scrollLastIndex >= chapters.length - 1,
            fetchingNext: _scrollFetchingNext,
            controller: _scrollController,
          );
  } else if (content.isEmpty) {
    readingArea = _buildEmptyContent(settings, textColor, chapterTitle);
  } else {
    final pages = _computePages(content, settings); // memoized 分页
    readingArea = ReaderPageMode(
      settings: settings, textColor: textColor,
      pages: pages, isLastChapter: effectiveIndex >= chapters.length - 1,
      controller: _pageController,
      onPageChanged: _onPageChanged,
      onChapterEnd: () => _handleNextChapterPage(chapters, effectiveIndex),
      onChapterEndRetry:
          _autoAdvanceFailed ? () => _handleNextChapterPage(chapters, effectiveIndex) : null,
      autoAdvancing: _autoAdvancing, autoAdvanceFailed: _autoAdvanceFailed,
    );
  }
  // Scaffold + Stack + ReaderTopBar + ReaderBottomBar（同原逻辑，不再赋值字段/注册回调）
  return Scaffold(backgroundColor: bg, body: Stack(children: [ /* GestureDetector + readingArea, ReaderTopBar, ReaderBottomBar */ ]));
}
```

### 设计要点

**翻页分页算法（paginateChapter）计入段距：**

当前算法用单一 TextPainter 度量整段内容，按「每页固定行数」切片（`linesPerPage = availHeight / lineHeightPx`），不感知段落边界，`\n` 仅作换行无额外间距。

改为**按行累计高度含段距**：仍用单一 TextPainter 取全部行度量（`computeLineMetrics()`），但先标记每行是否为段末（该行末字符为 `\n`），再按累计高度（行高 + 前一行段末则加 `paragraphSpacing`）分页，使段间留白被正确计入页高，避免段落被切到两页时段距丢失或溢出。

**关键代码要点 - novel_paginator.dart：**

```dart
/// 翻页模式分页（纯函数，计入段距）
///
/// 用 TextPainter 行度量按行分页；段末行（源串对应位置为 \n）之后插入
/// [paragraphSpacing] 额外间距，计入下一行起始高度，保证段距不被截断。
List<String> paginateChapter(
  String content,
  double width,
  double availHeight,
  double fontSize,
  double lineHeight,
  double paragraphSpacing, // 新增
) {
  if (content.isEmpty) return [''];
  final painter = TextPainter(
    text: TextSpan(text: content, style: TextStyle(
      fontSize: fontSize, height: lineHeight,
      fontFamily: AppTextStyles.cjkFontFamily)),
    textDirection: TextDirection.ltr, maxLines: null,
  );
  painter.layout(maxWidth: width);
  final metrics = painter.computeLineMetrics();
  if (metrics.isEmpty) return [content];
  final lineHeightPx = metrics.first.height;
  if (lineHeightPx <= 0) return [content];

  // 标记段末行：取下一行起始 offset，若前一字符为 \n 则当前行段末
  final n = metrics.length;
  final endsParagraph = List<bool>.filled(n, false);
  for (var i = 0; i < n; i++) {
    final nextStart = (i + 1 < n)
        ? painter.getPositionForOffset(
              Offset(0, metrics[i + 1].baseline - lineHeightPx * 0.5)).offset
        : content.length;
    if (nextStart > 0 && content.substring(nextStart - 1).startsWith('\n')) {
      endsParagraph[i] = true;
    }
  }

  // 按累计高度分页（首页首行不加段距；非首行且前一行段末才加段距）
  final pages = <String>[];
  var pageStart = 0;
  var used = 0.0;
  for (var i = 0; i < n; i++) {
    final firstOnPage = i == pageStart;
    final gap = firstOnPage
        ? 0.0
        : (endsParagraph[i - 1] ? paragraphSpacing : 0.0);
    if (!firstOnPage && used + gap + lineHeightPx > availHeight) {
      pages.add(_slice(content, painter, metrics, pageStart, i));
      pageStart = i;
      used = lineHeightPx;
    } else {
      used += gap + lineHeightPx;
    }
  }
  if (pageStart < n) pages.add(_slice(content, painter, metrics, pageStart, n));
  return pages;
}

/// 取 [start, end) 行的文本切片（复用原 offset 计算）
String _slice(String content, TextPainter painter,
    List<LineMetrics> m, int start, int end) {
  final startOffset = painter
      .getPositionForOffset(Offset(0, m[start].baseline - m.first.height * 0.5))
      .offset;
  final endOffset = end < m.length
      ? painter.getPositionForOffset(Offset(0, m[end].baseline - m.first.height * 0.5)).offset
      : content.length;
  return content.substring(startOffset, endOffset);
}
```

```dart
void _prefetchNextChapter(List<NovelChapter> chapters, int index) {
  final next = index + 1;
  if (next >= chapters.length) return; // 已是最后一章

  unawaited(_ensureChapterBodyReady(chapters, next));
```

```dart
    if (mounted) AppSnackbar.show(context, '上一章加载失败，请重试');
    return;
  }
  // 用带正文的实例替换后切章，并标记跳末页
  final refreshed = List.of(chapters);
  refreshed[prevIndex] = ready;
  _jumpToEndOnRestore = true;
  _goToChapter(prevIndex, refreshed);
}
```

**关键设计点：**

1. **拆分顺序：先拆分后功能。** 文件已 3x 超红线，先拆分降风险 + 修复 build 副作用，功能建在已验证小文件上。每个功能在拆分后有明确归属文件，非散落。

2. **part 文件 mixin 解决私有可见性。** Dart mixin 在独立文件无法访问主 State 私有字段。用 `part 'reader_chapter_fetcher.dart';` 使 mixin 与主文件同库，mixin 内可读写 `_novel`/`_loadingChapterId` 等私有字段，避免改公有或传参爆炸。`_ReaderChapterFetcher`（抓取/预取/自动翻章）+ `_ReaderProgress`（进度/恢复/滚动连续阅读）两个 mixin，跨 mixin 共享字段（`_scrollChapters`/`_chapterBases`）仅在 progress mixin 声明。

3. **段距分页（paginateChapter）按行累计高度含段距。** 仍用单一 TextPainter 取全部行度量，但标记每行段末（下一行起始 offset 前一字符为 `\n`），分页时非首行且前一行段末则加 `paragraphSpacing` 到累计高度，使段间留白正确计入页高，避免段落跨页时段距丢失。`_slice` 复用原 offset 计算取文本切片。

4. **预取幂等。** `_prefetchNextChapter` 复用 `_ensureChapterBodyReady`（内含 `content.isNotEmpty` 守卫），fire-and-forget 写回 DB，chaptersProvider 流自动刷新。重复预取不重复请求；预取失败静默（仅 debugPrint），真正翻章失败才 toast。

5. **滑块跳章 onChangeEnd。** `onChanged: (_) {}` 允许拖动视觉但不跳章（避免频繁切章），`onChangeEnd` 才调 `_goToChapter`。章数<=1 隐藏滑块。`divisions=章数-1` 吸附到章。

6. **上一章衔接 _jumpToEndOnRestore 标志。** `_goToPreviousChapterLastPage` 先 `_ensureChapterBodyReady(prevIndex)`（预取可能已抓到，否则现抓），成功后置 `_jumpToEndOnRestore=true` + `_goToChapter(prevIndex)`。`_goToChapter` 设 `_restored=false` 触发 post-frame `_maybeRestore`，其翻页分支检测标志跳 `_pages.length-1` 并复位标志。失败 toast 不切章。

7. **build 副作用修复：ref.listenManual + 调度式 post-frame。** `_settings`/`_latestChapters` 由 initState 的 `ref.listenManual`（`fireImmediately`）缓存；post-frame 工作（restore/fetch/prefetch）由 `_schedulePostFrameWork` 用 `_postFrameScheduled` 守卫注册一次，在 listen 回调触发。回调帧末执行，控制器已有 clients，可安全定位。build 仅读 AsyncValue 传参，不写字段不注册回调。

**Concerns / 偏离 spec 说明：**

- **part 文件 vs 独立 mixin 文件：** spec 写「reader_chapter_fetcher.dart（或 mixin）」。本 plan 用 `part` 文件实现 mixin，因独立文件 mixin 无法访问主 State 私有字段（Dart 私有为库级）。part 文件使 mixin 同库，保留私有封装。part 文件每文件 < 300 行满足红线（物理文件计数）。若团队不偏好 part 文件，可改为「字段改 package-private（去下划线）+ 独立 mixin 文件」，但违反 CLAUDE.md 私有命名规范，故不采用。

- **分页缓存 memoize 在 build：** `_computePages` 在 build 中计算并写缓存字段（`_paginateContent` 等），技术上属 build 内副作用。但这是 Flutter 标准 memoization 模式（幂等派生计算，无外部副作用），spec 仅要求移出 `_settings`/`_latestChapters`/`addPostFrameCallback` 三项，未要求移除分页缓存。保留以避免每次 build 重算 TextPainter（性能损耗）。如需严格合规，可改为 `useMemoized` 或独立 controller，但超出本次范围。

- **滑块拖动不实时更新进度文本：** `onChanged` 空回调，进度文本在 `onChangeEnd` 跳章后才更新。若需拖动实时预览，需加局部状态（YAGNI，后置）。

- **预取上一章未做：** 仅预取下一章（Task 4）。上一章衔接（Task 7）在 page==0 时现抓上一章正文，若预取未覆盖则仍有 loading。因用户翻页方向主要向后（下一章），向前频次低，不预取上一章以省流量（YAGNI）。
