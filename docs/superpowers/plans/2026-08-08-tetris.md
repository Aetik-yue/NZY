### 设计要点（spec 具体化）

- **棋盘：** 10 列 × 20 行可见，**无隐藏 buffer**（spec 的 40 行/20 buffer 会使方块从生成到可见在 L0 耗时 20s，手感不可用）。方块在可见区顶部生成（origin row=0）；旋转用 SRS kick 表处理顶部贴边，box 偏移恒非负故无负行。Game Over = 生成位与已占格重叠（Block out）。Lock out 在无 buffer 下退化为 Block out，不再单列。
- **SRS 旋转：** 每方块 4 状态（0/R/2/L）。仅存 spawn 偏移 + box size，旋转态由 CW 变换 `(r,c) -> (c, size-1-r)` 迭代计算（最多 3 次，4 格，开销可忽略），避免手写 28 组偏移的转录错误；O 不旋转。
- **Wall Kick：** JLSTZ 与 I 各 8 组（CW+CCW 各 4 转换），存为 `Map<(int from,int to), List<({int dc,int dr})>>`，`dc`=列偏移、`dr`=行偏移（正=向下）。由标准 SRS 表（y-up）转换得来：`dr = -y`。
- **7-bag：** `TetrominoType.values.toList()..shuffle(rng)`，队列耗尽自动补袋。
- **Gravity：** 级别->下落间隔（ms），L0=1000ms 递减到 L29+=20ms（趋近 20G）。
- **Lock delay：** 落地后累计 500ms 锁定；成功移动/旋转重置计时（上限 15 次防无限拖延）。

```dart
import 'dart:math';

import 'package:flutter/material.dart';
import '../../../app/theme/app_colors.dart';

/// 七种方块（warm pastel classic 配色）
enum TetrominoType { I, O, T, S, Z, J, L }

extension TetrominoTypeX on TetrominoType {
  /// 颜色：4 复用现有令牌 + 3 新增令牌
  Color get color => switch (this) {
        TetrominoType.I => AppColors.accentTeal,
        TetrominoType.O => AppColors.accentGold,
        TetrominoType.T => AppColors.accentRose,
        TetrominoType.S => AppColors.accentSage,
        TetrominoType.Z => AppColors.accentCoral,
        TetrominoType.J => AppColors.accentMauve,
        TetrominoType.L => AppColors.accentPeach,
      };
}

/// 格子坐标（命名记录，便于读 .r/.c）
typedef Cell = ({int r, int c});

/// 游戏状态
enum TetrisStatus { ready, playing, paused, gameOver }

/// 棋盘：10 列 × 20 行可见（无 buffer，方块顶部生成）
typedef TetrisBoard = List<List<TetrominoType?>>;

/// 生成空棋盘
TetrisBoard emptyBoard() => List.generate(20, (_) => List.filled(10, null));

/// 列数
const kTetrisCols = 10;
/// 行数（可见）
const kTetrisRows = 20;

// ──────── SRS：spawn 偏移（相对 origin 左上角）+ box 尺寸 ────────

const kSpawnCells = <TetrominoType, List<Cell>>{
  TetrominoType.I: [(r: 1, c: 0), (r: 1, c: 1), (r: 1, c: 2), (r: 1, c: 3)],
  TetrominoType.O: [(r: 0, c: 0), (r: 0, c: 1), (r: 1, c: 0), (r: 1, c: 1)],
  TetrominoType.T: [(r: 0, c: 1), (r: 1, c: 0), (r: 1, c: 1), (r: 1, c: 2)],
  TetrominoType.S: [(r: 0, c: 1), (r: 0, c: 2), (r: 1, c: 0), (r: 1, c: 1)],
  TetrominoType.Z: [(r: 0, c: 0), (r: 0, c: 1), (r: 1, c: 1), (r: 1, c: 2)],
  TetrominoType.J: [(r: 0, c: 0), (r: 1, c: 0), (r: 1, c: 1), (r: 1, c: 2)],
  TetrominoType.L: [(r: 0, c: 2), (r: 1, c: 0), (r: 1, c: 1), (r: 1, c: 2)],
};

const kBoxSize = <TetrominoType, int>{
  TetrominoType.I: 4,
  TetrominoType.O: 2,
  TetrominoType.T: 3,
  TetrominoType.S: 3,
  TetrominoType.Z: 3,
  TetrominoType.J: 3,
  TetrominoType.L: 3,
};

/// 计算方块在指定旋转态（0..3）下的格子偏移
///
/// 由 spawn 态应用 CW 变换 `(r,c) -> (c, size-1-r)` 迭代得到，
/// 避免手写 28 组偏移的转录错误；O 不旋转直接返回 spawn。
List<Cell> cellsOf(TetrominoType type, int rotation) {
  if (type == TetrominoType.O) return kSpawnCells[type]!;
  var cells = kSpawnCells[type]!;
  final size = kBoxSize[type]!;
  for (var i = 0; i < (rotation % 4); i++) {
    cells = [for (final p in cells) (r: p.c, c: size - 1 - p.r)];
  }
  return cells;
}

// ──────── SRS Wall Kick 表（dc=列偏移, dr=行偏移 正=向下）────────
// 由标准 SRS 表（y-up）转换：dr = -y。JLSTZ 与 I 各 8 组。

const kKicksJlStz = <(int, int), List<({int dc, int dr})>>{
  (0, 1): [(dc: 0, dr: 0), (dc: -1, dr: 0), (dc: -1, dr: -1), (dc: 0, dr: 2), (dc: -1, dr: 2)],
  (1, 0): [(dc: 0, dr: 0), (dc: 1, dr: 0), (dc: 1, dr: 1), (dc: 0, dr: -2), (dc: 1, dr: -2)],
  (1, 2): [(dc: 0, dr: 0), (dc: 1, dr: 0), (dc: 1, dr: 1), (dc: 0, dr: -2), (dc: 1, dr: -2)],
  (2, 1): [(dc: 0, dr: 0), (dc: -1, dr: 0), (dc: -1, dr: -1), (dc: 0, dr: 2), (dc: -1, dr: 2)],
  (2, 3): [(dc: 0, dr: 0), (dc: 1, dr: 0), (dc: 1, dr: -1), (dc: 0, dr: 2), (dc: 1, dr: 2)],
  (3, 2): [(dc: 0, dr: 0), (dc: -1, dr: 0), (dc: -1, dr: 1), (dc: 0, dr: -2), (dc: -1, dr: -2)],
  (3, 0): [(dc: 0, dr: 0), (dc: -1, dr: 0), (dc: -1, dr: 1), (dc: 0, dr: -2), (dc: -1, dr: -2)],
  (0, 3): [(dc: 0, dr: 0), (dc: 1, dr: 0), (dc: 1, dr: -1), (dc: 0, dr: 2), (dc: 1, dr: 2)],
};

const kKicksI = <(int, int), List<({int dc, int dr})>>{
  (0, 1): [(dc: 0, dr: 0), (dc: -2, dr: 0), (dc: 1, dr: 0), (dc: -2, dr: 1), (dc: 1, dr: -2)],
  (1, 0): [(dc: 0, dr: 0), (dc: 2, dr: 0), (dc: -1, dr: 0), (dc: 2, dr: -1), (dc: -1, dr: 2)],
  (1, 2): [(dc: 0, dr: 0), (dc: -1, dr: 0), (dc: 2, dr: 0), (dc: -1, dr: -2), (dc: 2, dr: 1)],
  (2, 1): [(dc: 0, dr: 0), (dc: 1, dr: 0), (dc: -2, dr: 0), (dc: 1, dr: 2), (dc: -2, dr: -1)],
  (2, 3): [(dc: 0, dr: 0), (dc: 2, dr: 0), (dc: -1, dr: 0), (dc: 2, dr: -1), (dc: -1, dr: 2)],
  (3, 2): [(dc: 0, dr: 0), (dc: -2, dr: 0), (dc: 1, dr: 0), (dc: -2, dr: 1), (dc: 1, dr: -2)],
  (3, 0): [(dc: 0, dr: 0), (dc: 1, dr: 0), (dc: -2, dr: 0), (dc: 1, dr: 2), (dc: -2, dr: -1)],
  (0, 3): [(dc: 0, dr: 0), (dc: -1, dr: 0), (dc: 2, dr: 0), (dc: -1, dr: -2), (dc: 2, dr: 1)],
};

/// 当前方块
class Piece {
  final TetrominoType type;
  final int rotation; // 0..3
  final int row;      // origin 行（box 左上）
  final int col;      // origin 列

  const Piece({
    required this.type,
    this.rotation = 0,
    this.row = 0,
    this.col = 3,
  });

  /// 绝对格子坐标
  List<Cell> absoluteCells() {
    final base = cellsOf(type, rotation);
    return [for (final p in base) (r: p.r + row, c: p.c + col)];
  }

  Piece copyWith({int? rotation, int? row, int? col}) => Piece(
        type: type,
        rotation: rotation ?? this.rotation,
        row: row ?? this.row,
        col: col ?? this.col,
      );
}

/// 7-bag 随机生成器（公平发牌）
List<TetrominoType> refillBag([Random? rng]) {
  final r = rng ?? Random();
  return TetrominoType.values.toList()..shuffle(r);
}

/// 碰撞检测（边界 + 已占格）
bool isValidPosition(TetrisBoard board, Piece piece) {
  for (final p in piece.absoluteCells()) {
    if (p.c < 0 || p.c >= kTetrisCols || p.r < 0 || p.r >= kTetrisRows) {
      return false;
    }
    if (board[p.r][p.c] != null) return false;
  }
  return true;
}

/// SRS 旋转 + wall kick
///
/// [dir] = +1 顺时针 / -1 逆时针。按序尝试 kick 表，首个合法位置生效；
/// 全部失败返回 null（方块不变）。O 不旋转。
Piece? rotate(TetrisBoard board, Piece piece, int dir) {
  if (piece.type == TetrominoType.O) return piece;
  final from = piece.rotation;
  final to = (piece.rotation + dir + 4) % 4;
  final kicks = piece.type == TetrominoType.I
      ? kKicksI[(from, to)]!
      : kKicksJlStz[(from, to)]!;
  for (final k in kicks) {
    final candidate = piece.copyWith(
      rotation: to,
      col: piece.col + k.dc,
      row: piece.row + k.dr,
    );
    if (isValidPosition(board, candidate)) return candidate;
  }
  return null;
}

/// 消除满行，返回消除数（就地修改 board，上方下移）
int clearLines(TetrisBoard board) {
  var cleared = 0;
  for (var r = board.length - 1; r >= 0; r--) {
    if (board[r].every((c) => c != null)) {
      board.removeAt(r);
      board.insert(0, List<TetrominoType?>.filled(kTetrisCols, null));
      cleared++;
      r++; // 该索引现已是原 r-1 行，抵消循环 r-- 以复检
    }
  }
  return cleared;
}

/// Block out 检测（spawn 位被占 -> 游戏结束）
bool isBlockOut(TetrisBoard board, Piece piece) => !isValidPosition(board, piece);

/// 消行分值（0..4 行）
const kLineScores = [0, 100, 300, 500, 800];

/// 级别 -> 下落间隔（L0=1s 递减到 L29+=20ms，趋近 20G）
///
/// spec 锚点：L0=1.0s / L9=0.11s / L19+=0.03s / L29+=0.02s。L15-28 平滑到 30ms。
Duration gravityInterval(int level) {
  const ms = [
    1000, 793, 618, 473, 355, 300, 218, 164, 135, 110, // 0-9
    88, 72, 57, 46, 38, 33, 30, 30, 30, 30, // 10-19
    30, 30, 30, 30, 30, 30, 30, 30, 30, // 20-28
  ];
  if (level >= 29) return const Duration(milliseconds: 20);
  return Duration(milliseconds: ms[level.clamp(0, ms.length - 1)]);
}

/// 生成 spawn 方块（顶部居中）
Piece spawnPiece(TetrominoType type) =>
    Piece(type: type, rotation: 0, row: 0, col: type == TetrominoType.I ? 3 : 3);
```

```dart
import 'package:flutter/material.dart';

import '../../../app/theme/app_colors.dart';
import 'tetris_model.dart';

/// 俄罗斯方块主绘制器
///
/// 棋盘 10×20，cellSize = width/10。绘制顺序：深底 -> 网格细线 ->
/// 已锁定格 -> Ghost 轮廓 -> 当前方块 -> 消行闪光（动画期间）。
class TetrisPainter extends CustomPainter {
  final TetrisBoard board;
  final Piece? current;
  final int ghostRow; // Ghost 方块 origin 行
  final Set<int> clearingRows;
  final double clearProgress; // 0..1

  const TetrisPainter({
    required this.board,
    required this.current,
    required this.ghostRow,
    this.clearingRows = const {},
    this.clearProgress = 0,
  });

  @override
  void paint(Canvas canvas, Size size) {
    final bgPaint = Paint()..color = AppColors.gameBgDark;
    canvas.drawRect(Offset.zero & size, bgPaint);

    final cell = size.width / kTetrisCols;
    // 网格细线
    final gridPaint = Paint()
      ..color = Colors.white.withValues(alpha: 0.05)
      ..strokeWidth = 1;
    for (var c = 1; c < kTetrisCols; c++) {
      canvas.drawLine(Offset(c * cell, 0), Offset(c * cell, size.height), gridPaint);
    }
    for (var r = 1; r < kTetrisRows; r++) {
      canvas.drawLine(Offset(0, r * cell), Offset(size.width, r * cell), gridPaint);
    }

    // 已锁定格
    for (var r = 0; r < kTetrisRows; r++) {
      for (var c = 0; c < kTetrisCols; c++) {
        final t = board[r][c];
        if (t == null) continue;
        final flash = clearingRows.contains(r);
        _drawBlock(canvas, _rect(c, r, cell), t.color,
            flash ? 1.0 - clearProgress : 1.0, flash);
      }
    }

    // Ghost（落点预览）：半透明轮廓
    if (current != null && clearingRows.isEmpty) {
      final ghost = current!.copyWith(row: ghostRow);
      for (final p in ghost.absoluteCells()) {
        if (p.r < 0 || p.r >= kTetrisRows) continue;
        final rect = _rect(p.c, p.r, cell).deflate(cell * 0.08);
        canvas.drawRRect(
          RRect.fromRectAndRadius(rect, Radius.circular(cell * 0.18)),
          Paint()
            ..style = PaintingStyle.stroke
            ..strokeWidth = cell * 0.08
            ..color = current!.type.color.withValues(alpha: 0.35),
        );
      }
    }

    // 当前方块
    if (current != null) {
      for (final p in current!.absoluteCells()) {
        if (p.r < 0 || p.r >= kTetrisRows) continue;
        _drawBlock(canvas, _rect(p.c, p.r, cell), current!.type.color, 1.0, false);
      }
    }
  }

  Rect _rect(int c, int r, double cell) =>
      Rect.fromLTWH(c * cell, r * cell, cell, cell);

  /// 绘制单格：2-stop 渐变 + 圆角 + 内高光描边；[flash] 时叠加白色闪光
  void _drawBlock(Canvas canvas, Rect rect, Color color, double alpha, bool flash) {
    final rrect = RRect.fromRectAndRadius(
      rect.deflate(rect.width * 0.04),
      Radius.circular(rect.width * 0.16),
    );
    final paint = Paint()
      ..shader = LinearGradient(
        begin: Alignment.topLeft,
        end: Alignment.bottomRight,
        colors: [
          color.withValues(alpha: 0.95 * alpha),
          color.withValues(alpha: 0.72 * alpha),
        ],
      ).createShader(rect);
    canvas.drawRRect(rrect, paint);
    canvas.drawRRect(
      rrect,
      Paint()
        ..style = PaintingStyle.stroke
        ..strokeWidth = rect.width * 0.05
        ..color = Colors.white.withValues(alpha: 0.28 * alpha),
    );
    if (flash) {
      canvas.drawRRect(
        rrect,
        Paint()..color = Colors.white.withValues(alpha: clearProgress * 0.8),
      );
    }
  }

  /// 游戏循环每帧原地改写 board/current（同引用），引用比较恒 false，故始终重绘
  @override
  bool shouldRepaint(covariant TetrisPainter old) => true;
}

/// 单块预览绘制器（Hold / Next 面板用）
///
/// 在给定 [size] 内居中绘制 spawn 态方块，自动按 box size 缩放。
class TetrominoPainter extends CustomPainter {
  final TetrominoType? type;

  const TetrominoPainter({required this.type});

  @override
  void paint(Canvas canvas, Size size) {
    if (type == null) return;
    final cells = cellsOf(type!, 0);
    final boxSize = kBoxSize[type!]!;
    // 预览区给一点边距，方块占 box 的有效行列范围
    final maxR = cells.map((p) => p.r).reduce((a, b) => a > b ? a : b) + 1;
    final maxC = cells.map((p) => p.c).reduce((a, b) => a > b ? a : b) + 1;
    final cell = size.shortestSide / boxSize * 0.8;
    final offsetX = (size.width - maxC * cell) / 2;
    final offsetY = (size.height - maxR * cell) / 2;
    for (final p in cells) {
      final rect = Rect.fromLTWH(
        offsetX + p.c * cell,
        offsetY + p.r * cell,
        cell,
        cell,
      );
      final rrect = RRect.fromRectAndRadius(
        rect.deflate(cell * 0.06),
        Radius.circular(cell * 0.16),
      );
      canvas.drawRRect(
        rrect,
        Paint()
          ..shader = LinearGradient(
            begin: Alignment.topLeft,
            end: Alignment.bottomRight,
            colors: [type!.color.withValues(alpha: 0.95), type!.color.withValues(alpha: 0.72)],
          ).createShader(rect),
      );
    }
  }

  @override
  bool shouldRepaint(covariant TetrominoPainter old) => old.type != type;
}
```

### 控制与循环设计（spec 具体化）

- **游戏循环：** 复用打砖块 `createTicker` + `dt = (elapsed - lastTick).inMicroseconds / 16666`（归一化 60fps，高刷屏不加速）。每帧累加 `_gravityAccumMs`，达 `gravityInterval(level)` 下落 1 格。
- **Lock delay：** `_onGround = !isValidPosition(下移)`；落地后 `_lockAccumMs += dt*16.67`，达 500ms 锁定。成功移动/旋转且 `_lockResets < 15` 时重置 `_lockAccumMs` 并 `_lockResets++`。
- **控制量化：** `onPanUpdate` 水平拖动累计 `_dragDx`，每超过一格宽度 `cellWidth` 移动 1 列并消耗（1:1 跟手、量化到格）；垂直下拖累计 `_dragDy` 软降（每格 +1 分）；`onTap` 顺时针旋转。Hard Drop 按钮瞬时落底（+2/格）并锁定；Hold 按钮暂存/交换（每块限 1 次）。
- **消行动画：** 检测满行后 `_clearing=true`、记录满行行号；主 ticker 推进 `_clearProgress`（~300ms），期间锁输入；Painter 绘制满行白色闪光+淡出；完成后 `clearLines` 真正消除、计分、升级、生成下一块。
- **Ghost：** 每帧从当前方块向下试落，取最大合法 origin 行。
- **竖屏锁定：** `SystemChrome.setPreferredOrientations([portraitUp])`，dispose 恢复。

```dart
import 'dart:math';

import 'package:flutter/material.dart';
import 'package:flutter/scheduler.dart';
import 'package:flutter/services.dart';
import '../../../app/theme/app_colors.dart';
import '../../../app/theme/app_text_styles.dart';
import 'tetris_model.dart';
import 'tetris_painter.dart';
import 'tetris_status_overlay.dart';

/// 俄罗斯方块游戏页
class TetrisPage extends StatefulWidget {
  const TetrisPage({super.key});
  @override
  State<TetrisPage> createState() => _TetrisPageState();
}

class _TetrisPageState extends State<TetrisPage>
    with TickerProviderStateMixin {
  late final Ticker _ticker;
  Duration _lastTick = Duration.zero;

  TetrisBoard _board = emptyBoard();
  Piece? _current;
  TetrominoType? _hold;
  bool _holdUsed = false;
  List<TetrominoType> _nextQueue = [];
  final Random _rng = Random();

  int _score = 0, _level = 0, _lines = 0;
  TetrisStatus _status = TetrisStatus.ready;

  // gravity / lock delay
  double _gravityAccumMs = 0, _lockAccumMs = 0;
  int _lockResets = 0;
  bool _onGround = false;

  // 消行动画
  bool _clearing = false;
  double _clearProgress = 0;
  Set<int> _clearingRows = {};

  // 拖动量化累计
  double _dragDx = 0, _dragDy = 0;

  @override
  void initState() {
    super.initState();
    _ticker = createTicker(_onTick);
    _reset();
    SystemChrome.setPreferredOrientations([DeviceOrientation.portraitUp]);
  }

  @override
  void dispose() {
    _ticker.dispose();
    SystemChrome.setPreferredOrientations(DeviceOrientation.values);
    super.dispose();
  }

  void _reset() {
    _board = emptyBoard();
    _nextQueue = refillBag(_rng);
    _current = _spawnFromQueue();
    _hold = null;
    _holdUsed = false;
    _score = 0;
    _level = 0;
    _lines = 0;
    _gravityAccumMs = 0;
    _lockAccumMs = 0;
    _lockResets = 0;
    _onGround = false;
    _clearing = false;
    _status = TetrisStatus.ready;
  }

  Piece _spawnFromQueue() {
    if (_nextQueue.length <= 1) _nextQueue.addAll(refillBag(_rng));
    return spawnPiece(_nextQueue.removeAt(0));
  }

  void _start() {
    if (_status == TetrisStatus.ready || _status == TetrisStatus.paused) {
      setState(() => _status = TetrisStatus.playing);
      _lastTick = Duration.zero;
      _ticker.start();
    }
  }

  void _pause() {
    if (_status == TetrisStatus.playing) {
      _ticker.stop();
      setState(() => _status = TetrisStatus.paused);
    }
  }

  void _onTick(Duration elapsed) {
    if (!mounted) return;
    final dt = (elapsed - _lastTick).inMicroseconds / 16666.0;
    _lastTick = elapsed;
    if (dt <= 0 || dt > 4) return;
    if (_status != TetrisStatus.playing) return;

    if (_clearing) {
      _clearProgress += dt / 18; // ~300ms（18 帧@60fps）
      if (_clearProgress >= 1) _finishClear();
      setState(() {});
      return;
    }

    final piece = _current!;
    // gravity（ms 累加）
    _gravityAccumMs += dt * 16.6667;
    final intervalMs = gravityInterval(_level).inMilliseconds;
    while (_gravityAccumMs >= intervalMs) {
      _gravityAccumMs -= intervalMs;
      final moved = piece.copyWith(row: piece.row + 1);
      if (isValidPosition(_board, moved)) {
        _current = moved;
        _onGround = false;
      } else {
        _onGround = true;
        break;
      }
    }
    // lock delay
    _onGround = !isValidPosition(_board, piece.copyWith(row: piece.row + 1));
    if (_onGround) {
      _lockAccumMs += dt * 16.6667;
      if (_lockAccumMs >= 500) {
        _lockPiece();
        return;
      }
    } else {
      _lockAccumMs = 0;
    }
    setState(() {});
  }

  /// 移动（成功且原贴地时重置 lock delay）
  void _move(int dc) {
    if (_status != TetrisStatus.playing || _clearing) return;
    final moved = _current!.copyWith(col: _current!.col + dc);
    if (isValidPosition(_board, moved)) {
      _current = moved;
      _resetLockIfGrounded();
      setState(() {});
    }
  }

  void _rotate(int dir) {
    if (_status != TetrisStatus.playing || _clearing) return;
    final r = rotate(_board, _current!, dir);
    if (r != null) {
      _current = r;
      _resetLockIfGrounded();
      setState(() {});
    }
  }

  void _resetLockIfGrounded() {
    if (_onGround && _lockResets < 15) {
      _lockAccumMs = 0;
      _lockResets++;
    }
  }

  /// 软降一格（+1 分）
  void _softDrop() {
    if (_status != TetrisStatus.playing || _clearing) return;
    final moved = _current!.copyWith(row: _current!.row + 1);
    if (isValidPosition(_board, moved)) {
      _current = moved;
      _score += 1;
      _lockAccumMs = 0;
      setState(() {});
    }
  }

  /// 硬降：落到底 + 锁定（+2/格）
  void _hardDrop() {
    if (_status != TetrisStatus.playing || _clearing) return;
    var row = _current!.row;
    while (isValidPosition(_board, _current!.copyWith(row: row + 1))) {
      row++;
    }
    _score += (row - _current!.row) * 2;
    _current = _current!.copyWith(row: row);
    _lockPiece();
  }

  /// Hold：每块限 1 次
  void _holdSwap() {
    if (_status != TetrisStatus.playing || _clearing || _holdUsed) return;
    final cur = _current!.type;
    if (_hold == null) {
      _hold = cur;
      _current = _spawnFromQueue();
    } else {
      _current = spawnPiece(_hold!);
      _hold = cur;
    }
    _holdUsed = true;
    _lockAccumMs = 0;
    _lockResets = 0;
    _onGround = false;
    setState(() {});
  }

  /// Ghost origin 行（最大合法下落行）
  int _ghostRow() {
    if (_current == null) return 0;
    var row = _current!.row;
    while (isValidPosition(_board, _current!.copyWith(row: row + 1))) {
      row++;
    }
    return row;
  }

  void _lockPiece() {
    final piece = _current!;
    for (final p in piece.absoluteCells()) {
      if (p.r >= 0 && p.r < kTetrisRows && p.c >= 0 && p.c < kTetrisCols) {
        _board[p.r][p.c] = piece.type;
      }
    }
    _lockAccumMs = 0;
    _lockResets = 0;
    // 检测满行 -> 动画 / 否则直接生成下一块
    final full = <int>[];
    for (var r = 0; r < kTetrisRows; r++) {
      if (_board[r].every((c) => c != null)) full.add(r);
    }
    if (full.isNotEmpty) {
      _clearing = true;
      _clearProgress = 0;
      _clearingRows = full.toSet();
    } else {
      _spawnNext();
    }
    setState(() {});
  }

  void _finishClear() {
    final n = clearLines(_board);
    _clearing = false;
    _clearingRows = {};
    _clearProgress = 0;
    if (n > 0) {
      _score += kLineScores[n] * (_level + 1);
      _lines += n;
      _level = _lines ~/ 10;
    }
    _spawnNext();
  }

  void _spawnNext() {
    final next = _spawnFromQueue();
    if (isBlockOut(_board, next)) {
      _ticker.stop();
      _status = TetrisStatus.gameOver;
      return;
    }
    _current = next;
    _holdUsed = false;
    _lockAccumMs = 0;
    _lockResets = 0;
    _onGround = false;
    _gravityAccumMs = 0;
  }

  void _onPanUpdate(DragUpdateDetails d, double cellW, double cellH) {
    if (_status != TetrisStatus.playing || _clearing) return;
    _dragDx += d.delta.dx;
    _dragDy += d.delta.dy;
    // 水平：每格宽度移动 1 列
    if (_dragDx.abs() >= cellW) {
      final cols = (_dragDx / cellW).truncate();
      _move(cols);
      _dragDx -= cols * cellW;
    }
    // 垂直下拖：软降
    while (_dragDy >= cellH) {
      _softDrop();
      _dragDy -= cellH;
    }
    if (_dragDy < 0) _dragDy = 0; // 上拖忽略
  }

  @override
  Widget build(BuildContext context) {
    return PopScope(
      canPop: true,
      onPopInvokedWithResult: (didPop, _) {
        if (didPop) _ticker.stop();
      },
      child: Scaffold(
        backgroundColor: AppColors.bgPrimary,
        appBar: AppBar(
          backgroundColor: AppColors.bgPrimary,
          elevation: 0,
          leading: IconButton(
            icon: const Icon(Icons.arrow_back_ios_new, size: 20, color: AppColors.textPrimary),
            onPressed: () => Navigator.of(context).pop(),
          ),
          title: Text('俄罗斯方块', style: AppTextStyles.titleMedium),
          centerTitle: true,
          actions: [
            IconButton(
              icon: Icon(
                _status == TetrisStatus.playing ? Icons.pause_rounded : Icons.play_arrow_rounded,
                color: AppColors.textPrimary,
              ),
              onPressed: () => _status == TetrisStatus.playing ? _pause() : _start(),
            ),
          ],
        ),
        body: SafeArea(
          child: LayoutBuilder(
            builder: (context, c) {
              final fieldW = c.maxWidth * 0.62;
              final cellW = fieldW / kTetrisCols;
              final fieldH = cellW * kTetrisRows;
              return Column(
                children: [
                  // HUD
                  Padding(
                    padding: const EdgeInsets.symmetric(horizontal: 16, vertical: 6),
                    child: Row(
                      mainAxisAlignment: MainAxisAlignment.spaceAround,
                      children: [
                        _hud('分数', '$_score'),
                        _hud('级别', '$_level'),
                        _hud('行数', '$_lines'),
                      ],
                    ),
                  ),
                  const SizedBox(height: 4),
                  Expanded(
                    child: Row(
                      crossAxisAlignment: CrossAxisAlignment.start,
                      children: [
                        // 左：Hold + 按钮
                        SizedBox(
                          width: c.maxWidth * 0.19,
                          child: Column(
                            children: [
                              _panel('HOLD', _hold),
                              const SizedBox(height: 12),
                              _actionBtn('HOLD', AppColors.bgBlush, _holdSwap),
                            ],
                          ),
                        ),
                        // 中：游戏场
                        SizedBox(
                          width: fieldW,
                          height: fieldH,
                          child: GestureDetector(
                            behavior: HitTestBehavior.opaque,
                            onPanUpdate: (d) => _onPanUpdate(d, cellW, cellW),
```

**关键设计点：**
1. **SRS kick 表组织**：spawn 偏移 + box size 作为常量，旋转态由 CW 变换 `(r,c)->(c, size-1-r)` 迭代计算（避免手写 28 组偏移）；kick 表以 `(from,to)` 记录为 key，`dc`/`dr` 正向下/右，由标准 y-up 表 `dr=-y` 转换。JLSTZ 与 I 各 8 组（含 CW+CCW）。
2. **控制量化**：`onPanUpdate` 累计 `_dragDx`，每超一格宽度 `cellW` 移动 1 列并消耗（1:1 跟手、网格量化）；垂直下拖累计 `_dragDy` 软降（每格 +1 分）；`onTap` 旋转 CW。
3. **Lock delay**：`_onGround` 由「下移 1 格非法」判定；贴地后 `_lockAccumMs += dt*16.67`，达 500ms 锁定；成功移动/旋转且 `_lockResets<15` 重置计时并计数，防无限拖延。

**Concerns / 偏离 spec 说明：**
- **棋盘尺寸**：spec 写 10×40（20 buffer + 20 可见）。本 plan 具体化为 **10×20 可见、无 buffer**——因 20 行 buffer 会使方块在 L0（1s/行）耗时 20s 才进入可见区，手感不可用。box 偏移恒非负保证无负行，顶部贴边旋转由 kick 表兜底。Game Over 仅用 Block out（spawn 位被占），Lock out 在无 buffer 下退化为同义。如需严格还原 spec，可加回 2 行 buffer 用于 spawn，但需接受生成后 ~2s 不可见的轻微延迟。
- **T-spin / B2B / Combo / Perfect Clear**：spec 明确后置，本 plan 不实现（计分仅 Single/Double/Triple/Tetris × level）。
- **持久化最高分**：spec 后置，本 plan 内存记分。
- **消行动画**：用主 ticker 推进 `_clearProgress`（无第二个 AnimationController），期间锁输入，闪光+淡出 ~300ms 后真正消除——简化实现，视觉效果满足 spec「闪光->缩小淡出->下移」的核心诉求（下移由 `clearLines` 一次性 settle 完成）。
