# 项目记忆 · 以越之名（情侣恋爱空间 APP）

## 项目概述
- 面向情侣两人使用的私密恋爱空间 APP
- 平台：iOS + Android 跨平台
- 已完成 UI 设计稿（Ardot 画布），含首页/相册/我的 3 个核心页面（消息功能已移除）

## 设计规范
- 配色：暖奶油粉主题，主色玫瑰粉 #FF6B9D / #FF8FB1，辅助珊瑚 #FFB5A0、樱花粉 #FFD4E0
- 字体：中文 Sarasa Gothic SC，数字 Inter
- 圆角：卡片 24px，按钮 16-18px，导航胶囊 36px
- 风格：温馨浪漫、柔和、浅色粉系

## 功能模块
- 恋爱纪念日时间轴
- 共同相册管理（分类：全部/旅行/美食/日常）
- 愿望清单
- 每日打卡说"我爱你"（连续打卡天数）
- 内置音乐播放器
- 小说阅读器
- 备忘录

## 技术决策
- **跨平台框架**：Flutter（双端 UI 像素级一致、自绘引擎适合统一视觉、媒体能力成熟）
- **状态管理**：Riverpod
- **本地存储**：Isar（已落地，含代码生成 .g.dart）+ shared_preferences
- **路由**：IndexedStack（主 Tab）+ Navigator.push（子页面）
- **音乐播放**：just_audio（计划）
- **图片选择**：image_picker（已落地）
- **云同步**：Supabase（计划）
