## v1.1.0 大版本更新

### 双人同步

- 新增腾讯云 SCF + COS 双人同步：6 位情侣码创建/加入房间
- 支持愿望、待办、时光、打卡、纪念日、悄悄话和相册元数据同步
- 相册原图自动上传/下载；云端只保存稳定对象名，下载时刷新短时签名 URL
- 删除改为云端墓碑，避免另一台离线设备恢复后把已删除记录重新上传
- 首次同步先拉取再上传，避免应用重启后用旧本地副本覆盖云端新版
- 配对时识别双方相同的种子数据，避免重复记录

### 小说爬取性能

- 已知书源直接使用对应搜索和分类端点，减少无效 URL/参数轮询
- 主书源优先、备用源按需降级；公共搜索引擎只兜底一次
- 搜索与分类加入短期缓存，重复进入页面不再重复爬取
- 长篇目录和章节正文采用有界并发抓取，并保持原章节顺序
- 默认请求间隔由 1000ms 调整为 500ms，加入书架只预取首章

### 稳定性与安全

- 修复云端文档更新丢失 `cloudId` 导致重复、加入房间覆盖原成员等问题
- 修复照片选择路径位于系统缓存、缓存清理后照片丢失的问题
- 修复快速记录未初始化待办字段导致 Isar 写入崩溃的问题
- 修复打砖块击中任意砖块即过关、俄罗斯方块长按状态未取消的问题
- 云函数鉴权改为未配置即拒绝，并使用常量时间比较
- COS SDK 升级到 3.x；生产依赖审计为 0 个已知漏洞

### 核心功能

- 时光首页：纪念日主卡片、今日打卡、恋爱时间轴、打卡历史页
- 相册模块：九宫格浏览、时间轴浏览、照片全屏查看、添加照片
- 愿望清单：愿望列表、全部页、进度追踪、添加愿望
- 我的页面：情侣信息、统计面板、设置页

### 备忘录

- 备忘录列表、编辑页、搜索栏
- 标签筛选、作者筛选、日期分组
- 快速记录栏

### 小说

- 小说列表、详情页、阅读器
- 阅读器分页引擎、阅读控件、屏幕常亮
- 章节列表、阅读器设置面板
- 小说爬虫：笔趣阁源、内容清洗、GBK 编码支持、UA 轮换
- 添加小说弹窗、爬虫进度面板

### 音乐

- 本地音乐扫描与播放（just_audio + on_audio_query）
- 全新奶油白「回忆唱片」播放界面，重新设计播放控制页、歌单面板与迷你播放条
- 大封面使用 App 内「相册」的全部有效照片随机无重复轮播，不读取手机系统相册，不显示拍摄或记录日期
- 播放时每 12 秒自动切换回忆照片，暂停时冻结，切歌时立即切换；迷你播放条保留最后一张回忆
- 无可用回忆照片时自动回退到歌曲封面或渐变占位，并补强响应式布局与无障碍点击区域

### 游戏

- 打砖块（Breakout）：自定义绘制器、物理模型
- 俄罗斯方块（Tetris）：方块生成、消行、得分、控制手柄

### 专注

- 番茄钟模块：专注会话记录、设置持久化

### 纪念日

- 纪念日页面、时间轴组件、天数/周年计算

### 技术

- 构建工具链：AGP 8.11.1 + Kotlin 2.2.20 + Gradle 8.14.3
- 本地数据库：Isar 持久化存储
- 状态管理：Riverpod
- 依赖精简优化

### 部署提示

- v1.1.0 的删除墓碑、成员合并和云端 ID 修复依赖新版 `serverless/love-sync.zip`，请先重新部署云函数
- 正式 APK 必须通过 `--dart-define=SYNC_SECRET=...` 注入与云函数一致的随机密钥
- 为保证已安装旧版的设备可直接覆盖升级，v1.1.0 继续使用与历史 APK 一致的现有签名；后续迁移到独立 release keystore 需单独规划签名迁移或重新安装方案
