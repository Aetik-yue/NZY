## v1.4.0 应用内自动更新

v1.4.0 新增 Android 应用内更新。以后发布新版本时，只要在 GitHub 创建正式 Release，手机上的「以越之名」就会在打开应用时发现新版本，下载并校验安装包后直接调起系统安装页，不再需要反复传 APK 文件。

### 自动检查与提醒

- 应用启动后自动检查公开 GitHub Release，每天最多一次
- 发现更高版本时弹窗展示版本号、安装包大小和完整更新日志
- 无更新或网络失败时保持静默，不打断正常使用
- 「我的 → 设置 → 应用更新」提供手动检查入口，并显示当前版本
- 更新弹窗支持「稍后」和「取消下载」，下载期间不会误关弹窗

### 下载与安装

- 从 GitHub Release 资产下载 APK，支持镜像地址优先、GitHub 自动回退
- 下载完成后使用 SHA-256 校验安装包，校验失败立即停止安装并清理临时文件
- 安装包保存在应用私有缓存，通过 FileProvider 交给 Android 系统安装器
- 首次安装需要允许「以越之名」安装未知来源应用；授权后返回可点「重试安装」，无需重新下载
- 下载中断或取消会清理未完成文件，不会留下半成品 APK
- 更新失败会显示可读原因，可重新下载或重试安装

### 发布流程

- 新增 `scripts/build_android_release.ps1`，从 `pubspec.yaml` 读取版本号，构建 APK、生成 `.sha256` 和可选镜像清单 `latest.json`
- 支持 `-Publish` 调用 `gh` 创建 GitHub Release 并上传 APK 与校验文件
- 支持 `-UpdateBaseUrl` 注入静态镜像地址，镜像不可用时客户端自动回退 GitHub
- 详细步骤见 [应用内更新配置与发布](../../love_space/docs/APP_UPDATE_SETUP.md)

### 升级兼容性

- Android 包名继续保持 `com.lovespace.love_space`，不会安装成第二个应用
- Android 版本号升级为 `1.4.0+140`
- 本次更新不修改 Isar 数据库结构，不会删除已有照片、愿望、待办或其他本地数据
- 构建签名证书与 v1.3.1 一致（SHA-256 `7206848B62105DCC9EA3E62A7A2F11158F14B6705849E10441DCF68FAE52A6F6`），可以直接覆盖安装
- 首次启用自动更新必须先手动安装一次 v1.4.0；从 v1.4.1 起即可自动升级
