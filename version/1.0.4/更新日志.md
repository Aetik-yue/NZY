## v1.0.4 更新日志

### 新增功能

- 小说爬虫模块：支持从笔趣阁等来源在线抓取小说
- 爬虫架构：BaseCrawler 基类 + BiqugeCrawler 实现 + ContentCleaner 内容清洗
- 小说源管理（NovelSource）：多源配置与切换
- 爬虫配置（CrawlConfig）+ 爬虫日志（CrawlLog）持久化
- 网络层：AppHttpClient 封装 + UserAgent 轮换器
- 添加小说弹窗（add_novel_sheet）：输入 URL 即可抓取
- 爬虫进度面板（crawl_progress_sheet）：实时显示抓取进度

### 改进

- 新增 http、html 依赖用于网络请求和 HTML 解析
- 小说详情页优化
